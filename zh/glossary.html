8 周学习计划

按每周 8～10 小时设计。每周都有一个 LinkNote 里程碑——交付一个能跑的东西比读完所有章节更重要。

周阅读动手（LinkNote 里程碑）本周检验
100、01、02装好环境；跑通 hello.ts；创建 Vite + React 项目；写第一版 AGENTS.md能解释 tsc 与 node 运行 .ts 的区别
203、04写一个批量抓取网页标题的脚本：并发上限、超时、allSettled；用 Zod 定义 Bookmark 判别联合能预测事件循环输出顺序；代码中没有 any
305、06用假数据做出列表页：卡片、标签筛选（URL 状态）、空状态、添加表单能说出每一份状态住在哪里、为什么
407、08迁移到 Next.js 或 TanStack Start；接入数据库（Drizzle）和登录；实现增删查能画出一次请求经过的层与类型来源；删除接口防 IDOR
509、10部署上线（任选一个平台）；配置 CI；补齐单元测试和一个 E2E 测试有一个公网可访问的地址；PR 上 CI 自动运行
611异步摘要生成：队列 + 结构化输出 + 状态更新；流式“问我的收藏”（只读工具）建了 20 条样本的评估集；知道单次摘要的成本
712、13把“问我的收藏”升级为 Agent；为项目写 Skill 或 Hook；用六要素模板完成一个新功能一个功能从规格到合并，一次完成
814，复习为 LinkNote 写一份设计文档（含估算）；练习 5 道面试题（对着录音回答）能在 45 分钟内讲完 LinkNote 的系统设计
计划的正确用法

这是参考节奏，不是必须严格遵守的课表。如果你已经有明确的项目要做，就用自己的项目替代 LinkNote，按同样的顺序推进。最重要的原则只有一条：每周都交付一个能运行的东西，不要连续几周只读不做，也不要花一周时间“搭建完美的学习环境”。

最后

回到第 00 章的类比：从汇编到面向对象，工程师写的代码变少了，但对“系统如何运作”的理解要求并没有降低，反而扩展到了更高的层次。今天的转换也一样。Agent 会越来越强，但知道要什么、说得清楚、判断得了对错，这三件事始终是你的。
